YunX（云析）是一款网盘分享链接解析与高速下载工具。本目录是 Windows
免安装便携版：无需安装、无需自带 Java 运行时（已内置），解压后双击
"YunX Desktop.exe" 即可运行。

【使用说明】
- 首次启动会把内置 Chromium 内核解包到 %USERPROFILE%\.jcef-bundle
  （数秒，无需联网）；之后秒开。
- 应用数据保存在 %USERPROFILE%\.yunx-desktop（账号/任务/设置），
  下载默认到系统 Downloads。
- 账号登录：网盘账号页 ->「网页登录」（内置 Chromium 打开官方登录页，
  完成后自动抓取 Cookie / localStorage 登录态，含 HttpOnly 字段）；
  也可手动粘贴 Cookie / JWT；迅雷额外支持短信验证码登录。
- 主要功能：分享链接解析（夸克/UC/迅雷/百度/139/123）、文件浏览、
  高速分片下载、HLS 下载、下载管理、个人云盘浏览与文件夹递归下载。

【打不开？请先看这里】
本程序未做代码签名（数字签名证书），因此 Windows 可能提示风险：
- SmartScreen（"Windows 已保护你的电脑"）：点「更多信息」->「仍要运行」。
- 智能应用控制 Smart App Control（"智能应用控制已阻止可能不安全的应用"）：
  该功能只允许已签名且具有微软信誉的应用，未签名程序会被直接阻止且
  没有"仍要运行"选项。可选处理方式：
    1) 双击包内的 Start-YunX.bat：它用包内自带的、由 Java 厂商数字签名的
       java launcher 启动同一程序（无需安装 Java，也无需关闭该功能）；
    2) 在 设置 -> 隐私和安全性 -> Windows 安全中心 -> 应用和浏览器控制 ->
       智能应用控制 中关闭它（注意：关闭后需重装系统才能再次开启，请自行
       评估；公司/学校电脑通常无权限更改）；
    3) 等待带数字签名的版本。
- 也可右键 - 属性 - 数字签名 查看确认"无签名"，并配合发布页提供的
  SHA256 校验值核对文件完整性后再运行。
